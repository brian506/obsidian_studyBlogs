

## 1. String 형

> Key-Value 형태로 1대1로 값을 가지는 경우에 적합

![[스크린샷 2026-08-07 160202.png]]

- JSON 정보를 저장하기에도 용이

### 주요 명령어

1. GET: 키값 가져오기
	- `GET key`
2. SET : 키에 값 저장하기
	- `SET key value`
3. MGET: 여러 개의 키값 가져오기
	- `MGET key`

## 2. List 형

> 문자열의 리스트
> 여러 값을 순서대로 저장. 값을 삽입한 순서대로 유지

![[스크린샷 2026-08-07 173224.png]]

- 스택, 큐
- SNS 최신 게시물 등
- 로그

## 3. Hash 형

> 특정 객체를 값으로 저장
> 필드와 값의 쌍 집합

![[스크린샷 2026-08-07 173949.png]]

- 해시 내 각 필드에는 개별 TTL 설정 불가
