
## 리눅스 파일과 디렉터리 구조

| 파일 종류     | 설명                                |
| --------- | --------------------------------- |
| 일반 파일     | 데이터를 저장하는 대부분의 파일, 텍스트, 바이너리, 이미지 |
| 디렉터리 파일   | 다른 파일을 담는 파일, '폴더'에 해당            |
| 심볼릭 링크 파일 | 다른 파일을 가리키는 파일. '바로가기'와 비슷        |
| 장치 파일     | 디스크, 터미널 등 장치를 파일로 표현한것           |

## 주요 디렉토리

| 디렉터리  | 용도                      |
| ----- | ----------------------- |
| /bin  | 기본 명령어                  |
| /boot | 부팅에 필요한 커널 이미지와 부트로더 파일 |
| /dev  | 장치 파일(디스크, 터미널 등)       |
| /etc  | 시스템 설정 파일               |
| /home | 일반 사용자의 홈 디렉토리          |
| /lib  | 시스템 라이브러리               |
| /mnt  | 외부 장치를 임시로 연결하는 디렉토리    |
| /opt  | 패키지 관리자 외 별도 설치한 소프트웨어  |
| /proc | 현재 실행 중인 프로세스와 시스템 정보   |
| /root | 관리자의 홈 디렉토리             |
| /sbin | 시스템 관리 명령어              |
| /tmp  | 임시 파일                   |
| /usr  | 사용자용 프로그램과 라이브러리        |
| /var  | 가변 데이터(로그, 캐시, 메일)      |
**자주 사용하는 디렉토리**
- /etc, /var, /home 

## 명령어 기본 구조

`명령어 [옵션] [인수]`

### 옵션의 2가지 구조

```
ls -a 
ls -l
```

- -a : 숨김 파일 포함
- -l : 상세 정보 표시

### 명령어 팁

- tab 두번 누르면 후보 목록 표시
- ctrl + r 로 명령어 검색 가능

## 파일 시스템 명령어


| 명령어 | 의미                  |
| --- | ------------------- |
| pwd | 현재 작업 디렉터리의 절대경로    |
| cd  | 지정한 경로로 디렉터리 이동     |
| ls  | 디렉터리 안에 들어 있는 파일 목록 |
보통 ls -al 로 사용


## 파일 시스템 - df

> df는 디스크 공간의 통계 데이터, 디스크의 파일 시스템, 연결한 디렉터리를 보여줌

- 디스크의 파일 시스템과 디렉터리를 연결하는 것을 '마운트'라고 함
- df는 디스크별 공간이나 아이노드가 얼마나 남아있는지 확인하는 용도로 많이 사용

`df -h`
- 디스크 용량

`df -i`
- 아이노드의 사용 현황 
	- 아이노드란?
		- 파일이나 디렉터리의 정보를 기록하는 관리 데이터

## 파일 시스템 - mkdir ~ rmdir

### mkdir

> 지정한 이름의 디렉터리를 만든다.


| 옵션  | 의미                  |
| --- | ------------------- |
| -m  | 만들 디렉터리에 대한 사용권한 설정 |
| -p  | 상위 디렉터리까지 작성        |
| -v  | 실행 결과 화면에 출력        |
