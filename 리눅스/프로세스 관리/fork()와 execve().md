
## 새로운 프로세스를 생성하는 목적
### 1. 동일한 프로그램 처리를 여러 프로세스에 나눠서 처리

- fork() 사용
### 2. 다른 프로그램을 생성

- fork() / execve() 사용

### fork()

> 현재 실행 중인 프로세스(부모)를 복제해서 새로운 프로세스를 만드는 시스템 콜. 
> 호출 이후로 부모와 자식은 거의 동일한 상태에섯 독립적으로 실행

**fork()가 쓰여지는 상황**
- shell에서 명령어 실행할 때
- 즉, 새로운 프로그램을 실행할 땐 먼저 복제하고 다른 프로그램으로 exec한다.
###  fork() 함수 호출 시 동작 순서
1. 부모 프로세스가 fork() 호출
2. 자식 프로세스용 메모리 영역을 확보한 후 그곳에 부모 프로세스 메모리 복사
3. 부모 프로세스와 자식 프로세스는 둘 다 fork() 함수에서 복귀
4. 부모와 자식 프로세스는 서로 다른 두 PID를 반환

#### 자식 프로세스가 부모 프로세스를 복사해서 갖는 내용

- 주소 공간
- File Discriptor
- 환경변수, 실행 인자
- 현재 작업 디렉토리, umask, 리소스 제한 등

**동일한 프로그램 작업을 여러 프로세스로 나눠서 처리하는 것과 같이 메모리 복사는 적은 비용이 든다.** 


## 다른 프로그램을 기동하는 목적 

### execve()

> 하나의 복제된 프로그램 이후에 다른 프로그램을 실행시키기 위해서는 execve()를 호출한다.

fork()로 복사본 생성 이후에, 자식 프로세스에서 execve() 함수를 호출한다.
그러면 자식 프로세스는 새로운 프로그램으로 바뀐다.

#### 왜 굳이 새로운 프로그램으로 바꿔야함?

bash 부모 프로세스에서 복제를 하면, bash 프로그램만 사용할 수 있음.
근데 ls, cat, python 같은 프로그램도 실행시켜야 하므로 execve()가 순차적으로 호출되어 아예 다른 프로그램으로 실행된다.

### execve() 함수 호출 시 동작 순서

1. execve() 호출
2. execve() 함수 인자로 지정한 실행 파일에서 메모리에 배치하는데 필요한 정보를 가져옴
3. 현재 프로세스의 메모리를 새로운 프로세스 데이터로 덮어 씀
4. 프로세스를 새로운 프로세스의 최초에 실행할 명령부터 실행

fork는 새로운 프로세스를 만드는 것이고, execve는 새로운 프로세스 안의 내용을 다른 것으로 바꾸어 새로운 프로그램을 만드는 것.
