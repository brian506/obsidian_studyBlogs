**AI**
> 환경/데이터를 인지, 학습, 추론하여 목표 달성을 위한 예측/행동/선택/계획을 수행하는 시스템

**ML(머신러닝)**

## 학습의 정의와 과정

**과정**
1. 데이터(정답 쌍)를 기반으로
2. 가설공간 내 여러 함수 후보(모델)중
3. 예측 성능(손실 함수 등)이 가장 좋은 모델을 선택

**손실함수** : 예측값과 실제값의 차이를 측정하는 기준

**학습 루프** : 데이터 -> 모델 -> 학습 -> 평가 -> 개선 -> 반복

**함수 f(x)를 학습하는 이유**
- 예측 : 새로운 입력에 대해 label 추론
- 중요 특성 파악 : 어떤 feature가 label에 큰 영향을 주는가
- 해석 : 각 feature와 label간의 영향력 등 이해

## 지도학습

**정의** : 지도학습이란 입력값(feature)과 정답(label)이 쌍으로 주어진 데이터를 통해 모델이 예측 규칙을 학습하는 방법

**목표** : 훈련 데이터뿐만 아니라 처음 보는 데이터(테스트 데이터)에서도 높은 예측 성능을 내는 것

**구성 요소** 
- feature : 예측에 사용되는 입력 변수
- label : 실제 정답 또는 예측 대상

**과정**
- 훈련 데이터(입력 + 정답)로 모델 학습
- 새로운 데이터가 들어왔을 때 올바른 정답을 맞추는 함수 도출
- **일반화** : 훈련 데이터에만 과적합되지 않고, 처음 보는 데이터도 잘 예측할 수 있도록 하는 것

지도학습은 측정오차를 최소화하는 것이 아닌 **예측값과 정답의 차이**를 줄이는 것이 핵심
### 지도학습 문제의 유형

#### 1. 회귀 문제

**정의** : 결과값(라벨)이 연속적인 수치인 경우 (ex. 집값, 온도)
**목적** : 주어진 입력값에 대해 **숫자형 출력값**을 예측
**예시** 
- 공부 시간 -> 시험점수 예측
- 광고비 -> 매출액 예측

#### 2. 분류 문제
**정의** : 결과값(라벨)이 미리 정해진 범주중 하나인 경우
**목적** : 주어진 입력값으로 범주 분류
**예시**
- 이메일 내용/작성자 등 -> 스팸/정상 분류
- 종양 반경/면적/색깔 -> 악성/양성 분류

### 손실함수 (Loss Function)

**역할** : 예측값이 정답에서 얼마나 벗어났는지 하나의 숫자로 나타내는 함수
- 학습이란, 이 숫자가 작아지는 방향으로 모델을 고쳐 나가는 과정

### 분류 문제
#### Accuracy (정확도) 

> 분류 모델의 예측 정확도를 평가하는 지표

- 전체 예측 중에서 올바르게 맞춘 예측의 비율
	-> 올바른 예측 / 전체 예측

**정확도가 99%이면 좋은 모델일까?**
- 질병 데이터 1000명
	- 실제 환자 : 10명
	- 건강한 사람 : 990명

-> 무조건 모든 사람을 건강하다고 예측하는 문제 발생

- 정확도만 보지 말고 혼동행렬도 함께 봐야 안전

#### 혼동행렬

![](../../images/스크린샷%202026-08-16%2017.29.19.png)

**TP** : 참 / 양성
- 예측 : 코로나에 걸렸다
- 결과 : 실제 환자 예측 성공
**FN** : 거짓 / 음성
- 예측 : 코로나에 안걸렸다
- 결과 : 실제 환자인데 안걸렸다고 오탐
**FP** : 거짓 / 양성
- 예측 : 코로나에 걸렸다
- 결과 : 건강한 사람을 환자로 착각
**TN** : 참 / 음성
- 예측 : 코로나에 안걸렸다
- 결과 : 건강한 사람 제대로 판단

**정밀도** : 양성이라 판정한 것 중 진짜 양성의 비율
- TP / (TP + FP)

**재현율** : 진짜 양성 가운데 잡아낸 예측 양성 비율
- TP / (TP + FN)

-> 정확도, 혼동행렬, 재현율은 학습이 끝난 결과를 평가하는 지표
#### 교차 엔트로피

- 학습 중에 정답을 얼마나 확신했는지의 반영하는 손실 계산
- 정답에 준 확률이 높을수록 손실 작아짐
- 확률이 낮으면 손실이 급겨히 커짐

## 학습의 목적

### 일반화
> 훈련 데이터 뿐만 아니라 처음 보는 데이터에서도 높은 예측을 성공할 수 있도록

### 오버피팅 (Overfitting)
> 훈련 데이터의 잡음까지 과도하게 외워버려서, 훈련 성능은 높으나 테스트 성능이 떨어지는 현상

- 훈련 데이터는 모집단의 일부 표본이라 과하게 맞추어 학습하면 예측이 크게 흔들림

### 언더피팅 (Underfitting)
> 모델이 단순하거나 충분히 학습되지 않아 중요한 패턴을 놓치는 현상

- 훈련/테스트 오류 모두 높음


## 교차검증

- 머신러닝은 데이터를 활용해 최적의 예측 모델을 만드는 작업
- 모델이 **처음 보는 데이터(테스트 데이터)** 에서 얼마나 잘 작동하는지,일반화 성능 최적화가 목표
- 평가를 위해 2가지 오류를 정의
	- 훈련 오류 : 학습에 사용된 데이터에서의 예측 오류
	- 테스트 오류 : 학습에 사용하지 않은 새 데이터에서의 예측 오류
- 학습의 목적은 테스트 오류를 최소화하는 모델을 찾는 것
- 현실적으로 충분한 테스트 데이터를 확보하기 어렵기 때문에, 한정된 데이터를 효율적으로 사용해 테스트 오류를 합리적으로 추정
- 일반적으로 훈련 오류는 테스트 오류보다 작고, 복잡도가 증가하면 훈련 오류는 계속 줄지만, 테스트 오류는 점점 커짐

### 테스트 오류 추정 방법

#### 검증셋(Validation Set, Hold-Out) 방법

- 데이터를 무작위로 훈련셋과 검증셋으로 분할
- 훈련셋에서 모델을 학습, 검증셋에서 성능 측정

**한계** : 분할에 따라 결과가 매우 변동적, 전체 데이터로 학습하지 않아 테스트 오류를 과대추정할 수 있음

#### K-겹 교차검즘 (K-fold Cross-Validation)

- 전체 데이터를 K개의 폴드로 나눈 뒤, 각 폴드를 한 번씩 검증셋으로 사용
- 각 반복마다 나머지 K-1개 폴드로 모델 학습, 남은 폴드로 성능 평가
- K번의 결과를 **평균해 테스트 오류 추정**
- 모든 데이터가 한 번은 검증에 사용됨 -> 검증 결과가 덜 변동적, 데이터 활용률 증가
	- 교차 검증은 **각 폴드 별 데이터가 겹치지 않도록** 분리해야함

#### Leave-One-Out 교차검증 (LOOCV)  vs K-겹 교차검증 비교

- **LOOCV**: 관측치가 n개라면 n번 반복(연산량 많음, 시간 오래 걸림)
- **K-겹 교차검증**: 연산량이 LOOCV보다 훨씬 적다. 보통 K=5~10 많이 사용.
- 실제 성능 차이는 크지 않음(적절한 K 선택 중요)

## 비지도 학습

> 라벨(정답)이 없는 데이터에서 구조, 패턴, 그룹을 발견하는 과정 의미

**예시**
- 군집화(클러스터링) : 유사한 데이터끼리 묶기
- 차원 축소 
- 이상치 탐지 등

- 무엇을 비슷함/다름으로 볼 것인가(거리, 유사도)
- 전처리를 어떻게 할 것인가
- **정답(라벨)을 예측하는게 아니라 데이터의 구조, 요약 정보, 임베딩 등**

### 클러스터링(군집화)
> 데이터 안에서 유사한 집단을 찾는 다양한 기법의 총칭

**집단 내부** : 비슷한 성격끼리 묶이도록 만드는 것
- 클러스터 내부에서는 최대한 유사
**집단 사이** : 서로 다른 부류는 확실히 다르게 구분
- 클러스터 끼리에서는 최대한 상이

### 대표 클러스터링 기법

#### K-means 클러스터링

**특징**
- 클러스터 수 K 미리 지정
- 각 데이터 포인트를 K개 클러스터로 분할. 각 클러스터 내부 변동의 합 최소화
- 하나의 데이터가 여러 그룹에 속할 수 없음
**목표** : 클러스터 거리 차이의 합이 최소가 되도록 데이터를 나누는 것

**알고리즘 단계**
1. 초기화 : 무작위로 K개 클러스터 할당
2. 반복 
	- 각 클러스터 중심 계산
	- 각 데이터를 가장 가까운 중심으로 재할당
	- 할당 변화 없을 때까지 반복
3. 특징
	- 빠르고 대용량 데이터에 효율적
	- 초기값에 따라 결과 달라짐
		- **지역 최소값 문제**

#### 계층적 군집

**특징**
- 덴드로그램을 통해 전체 구조를 시각적으로 제공
- 데이터 간 병합 과정을 통해 클러스터 형성

isolation forest는 클러스터링 단계가 없어 다른 비지도 학습보다 매우 빠름
