## 워드 임베딩과 순환신경망 기반 모델

### 원-핫 인코딩

**개념** : 단어를 벡터의 한 성분만 1, 나머지는 모두 0으로 표현
- 단어 수만큼의 차원을 갖는 희소 벡터
**단점**
- 어휘 수가 커질수록 벡터의 차원이 폭증
- 의미적으로 가까운 단어도 전혀 다른 벡터로 표현
- 유사도 계산 불가

### 워드 임베딩

**개념** : 단어들 사이의 의미적 관계를 포착할 수 있는 밀집되고 연속적/분산적 벡터 표현으로 나타내는 방법
- 저차원의 밀집 벡터
**기법** : Word2Vec

- Skip-grams 방식
	- **중심 단어를 통해 -> 주변 단어들을 예측**하는 방법
	- 단어의 위치에 크게 구애 받지 않음
	- 강아지 라는 중심단어를 보고 주변에 산책, 간식이 올것을 예측하게 학습
	- 적은 데이터에도 잘 동작
	- 희귀 단어나 구 표현에 강하다
	- 학습 속도가 느림
- Continuous Bag of Words (CBOW) 방식
	- **주변 단어들을 보고 -> 중심 단어 예측**
	- 학습 속도가 빠름
	- 자주 나오는 단어에 강함
	- 희귀 단어 표현에 약함

### 순차적 데이터

**특징**
- 순서 중요
- 장기 의존성
	- 멀리 떨어진 과거의 정보가 현재/미래에 영향을 줌
- 가변 길이
	- 순차 데이터는 길이가 일정하지 않고, 단어 수도 제각각
MLP,CNN등 고정된 길이의 입력을 받아 가변 길이의 데이터를 처리하기에 적합하지 않음

### RNN
> 이전 입력을 기억하고, 순차적 데이터 처리에 적합


![](../../images/스크린샷%202026-08-18%2022.28.12.png)

- 이전 시점의 정보를 담는 hidden state 보유
- 한 번에 하나의 요소를 처리하고, 정보를 앞으로 전달
- RNN은 hidden state를 유지하면서 가변 길이 데이터를 처리

#### 기울기 소실 문제 
> 딥러닝에서 역전파 시 앞쪽 층의 기울기가 0에 가까워져서 장기 의존성 학습이 어려워지는 현상

- 장기 의존성은 학습하지 못하고, 단기 의존성만 포착
	- 문장이 조금만 길어지면, 아주 예전에 읽었던 첫 단어의 기억이 점점 희미해져 까먹음

### LSTM

**특징**
- hidden state : 단기 기억
	- 현재 내보낼 출력값과 관련
- cell state : 장기 기억
	- 정보를 읽고, 지우고, 기록


#### 3가지 Gate

**Forget Gate**
- 이전 cell state에서 무엇을 버리고 무엇을 유지할지 결정

**Input Gate**
- 새 정보 중 얼마나 cell state에 쓸지 결정

**Output Gate**
- cell state 중 얼마나 hidden state로 내보낼지 결정

## 언어 모델

> 한 문장의 확률은 각 단어의 조건부 확률들의 곱으로 표현 가능

조건부 확률 : 사건 B가 일어났을 때 사건 A가 일어날 확률

### N-gram
![](../../images/스크린샷%202026-08-18%2022.49.37.png)

**한계** : 앞의 3단어 혹은 4단어만 보고 다음 단어를 맞추는 방식이라 문맥이 길어지면 정확도 낮음

### Seq2Seq

NMT란? 
- 인공 신경망을 이용해 기계 번역을 수행하는 방법
이때 사용되는 신경망 구조를 Seq2Seq라고 함

#### 주요 구조

**Encoder** : 한 LSTM은 입력 시퀸스를 처음부터 끝까지 읽어서, 핵심의 의미를 하나의 고정된 크기의 암호문으로 압축
**Decoder** : 다른 LSTM은 앞에서 얻은 벡터로부터 출력 시퀸스를 생성

#### 사용 예시
- 요약 : 긴 길이의 문서를 읽고, 짧은 길이의 문장으로 요약된 텍스트를 출력하는 태스크
- 대화 : 사용자의 발화를 기반으로, 맥락에 맞는 대답을 생성하는 태스크
- 코드 생성 : 자연어로 작성된 설명으로 코드 출력하는 태스크

#### Seq2Seq 학습 수행 - **Teacher Forcing**

> 모델이 스스로 예측한 단어 대신 정답 단어를 decoder 입력으로 넣어줌으로써 안정적이고 빠르게 학습을 수행하는 방법

**결과를 뽑는 방식**
- Greedy : 매 순간 가장 확률이 높은 단어만 고름
	- 빠르지만 전체 문장이 어색할 수 있음
	- 되돌리기 불가
- Beam Search 
	- 체스할 때 몇 수 앞을 내다보는 것과 동일
	- 1등 단어 뿐만 아니라 2,3등 단어들도 후보로 살려둔채 문장을 만들어보고
	- 최종적으로 가장 자연스러운 문장 선택

#### Seq2Seq의 한계 - **bottleneck problem**

- 인코더는 입력 문장 전체를 하나의 벡터로 요약하는데, 마지막 hidden state에 문장의 모든 의미 정보가 담김
- 고정 길이 벡터 하나에 모든 문장의 의미를 압축하다 보니 정보 손실이 나는 경우


### Attention
- bottleneck 문제 해결 방안

> decoder가 단어를 생성할 때, encoder 전체 hidden state 중 필요한 부분을 직접 참조

- 매 타입스텝마다 어떤 단어/구절에 집중할지를 가중치로 계산
	- 디코더가 단어를 뱉어낼 때, 인코더가 준 하나의 요약본에만 의존하는 것이 아니라 **원본 문장 전체를 다시** 참고

**장점**
- NMT 성능 향상
- Bottleneck 문제 해결
- Vanishing Gradient Problem 완화
	- 멀리 떨어진 단어도 직접 연결
