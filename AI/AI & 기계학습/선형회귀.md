> 입력 변수와 출력 변수 사이의 관계를 직선 형태로 근사하여, 예측하는 통계적 방법

**입력 변수 (x)** : 원인이 되는 데이터
**출력 변수 (y)** : 결과가 되는 데이터, 예측하고 싶은 값

**목적** : 입력 변수와 출력 변수 간의 선형 관계를 찾고, 이를 통해 예측 및 해석을 수행하는 것

## 단순 선형 회귀
> 한 개의 변수 x와 변수 y 사이의 선형 관계를 찾는 방법

**목표** : 데이터를 가장 잘 설명하는 직선을 찾아 예측에 활용

### 최소 제곱법
> 가장 최적의 직선을 찾는 원리

- 실제 관측값과 예측값의 차이(잔차)를 제곱해 합한 값을 최소화하는 방법
	- **잔차란?** : 실제 데이터와 예측 직선 사이의 거리
	- 잔차가 작을수록 예측 굿

**잔차 제곱합**
- 잔차들을 그냥 더하면, 플러스와 마이너스가 섞여서 0이 될 수도 있는 문제 발생
	-> 모든 **잔차를 제곱해서** 양수로 만든 다음에 다 더함
- 잔차제곱합이 가장 작아지는 순간의 직선을 최종 정답으로 채택

### 회귀 모형의 해석 - 가장 최적의 직선을 찾아냈을 때

- **절편 (b)** : x가 0일때의 y값
	- 예) TV 광고비를 0원 썼을 때 기본적으로 발생하는 매출액은?
- **기울기 (a)** : x가 1단위 증가할 때 y가 얼마나 변하는지를 보여주는 영향력의 크기
	- 예) TV 광고비를 1만원 늘릴 때마다, 매출액은 평균적으로 몇 만원 씩 오르는가?

### 결과 해석 - 실제로 최적의 직선인가?

**결정계수 ($R^2$) 란?**
- 0에서 1사이의 값을 가짐
- 1에 가까울수록 : 데이터 점들이 직선에 붙어있다는 뜻.
	- 예측이 매우 정확
- 0에 가까울수록 : 점들이 직선 주변에 난잡하게 흩어져 있음
	- 예측 부정확

## 다중선형회귀

> 원인(x)이 2개 이상일때, 결과(y)를 예측하는 모델


![](../../images/스크린샷%202026-08-16%2019.13.31.png)

- Y : 예측하고 싶은 최종 결과
- X : 결과에 영향을 미치는 여러 원인들 (예. TV 광고비, 라디오 광고비 등)
- 베타 : 각 원인이 결과에 미치는 영향력(가중치)
- 오차 : 통제할 수 없는 우연적인 오차

### 결과 해석

**변수가 여러 개일 때 기울기를 해석하는 방법**
- 반드시 다른 변수들은 고정임을 가정

**상황** : 매출액(Y)을 예측하기 위해 여러 X들을 넣었을 때, 기울기1이 3.5가 나왔을 때
**해석** : 다른 X 변수들은 고정해놓고 X1만 1단위 늘리면 Y는 평균 3.5단위로 증가

### 실제 분석 결과(성적표) 읽는 법

1. **적합도 ($R^2$):**
    "우리가 투입한 여러 원인($X_1, X_2, \dots$)들이 총매출액(Y)의 변화를 몇 %나 설명하는가?" (1에 가까울수록 성능이 좋음)

2. **p-value (유의확률):**    
    여러 변수를 넣다 보면 쓸모없는 변수도 섞여 들어갑니다. p-value는 "이 원인이 진짜로 결과에 영향을 미치는 게 맞나? 그냥 우연히 숫자가 그렇게 나온 건 아닐까?"를 검증해 주는 수치입니다.
    - 보통 이 값이 **0.05 (5%)보다 작으면** "통계적으로 유의미하다(이 변수는 진짜로 쓸모가 있다)"라고 판단하여 모델에 남겨둡니다.

### 다중선형회귀 주의사항

#### 변수를 추가할 때 (다중공산성)
**장점** : 더 많은 정보를 고려할 수 있어 설명력 향상
**단점** : 불필요한 변수를 넣게 되면 과적합 위험 커지고 해석 복잡


## 선형회귀 주의사항

- **오버피팅 (과적합)**
	- 훈련 데이터에서는 적합이 잘 되어있겠지만, 테스트 성능을 과소평가할 가능성 높음
	- 테스트 데이터에서의 일반화 부족
-> 검증/교차검증을 통해서 적절한 적합을 찾아야함

#### 선형회귀 해석시 주의 사항

- 이상적 상황 : 변수들이 연관되지 않고 독립적일 때 -> 계수 해석 명확
- 문제 상황 : 변수들이 서로 연관되어 있다면 -> 계수 추정이 불안정해지고 해석에 혼동 발생
- 주의 : **데이터의 상관관계로 인과 관계를 주장하면 안됨**
